# 두 iPhone 연결·촬영

한 대는 고객폰, 다른 한 대는 매장폰으로 사용합니다. 두 폰과 Mac을 같은 Wi-Fi에 연결하고 촬영하는 동안 Mac 서버와 앱을 켜 두세요. 실제 매장 웨이팅·할인 시스템과는 연결되지 않습니다.

## 준비

1. Mac에서 이 저장소 폴더를 열고 `npm install`을 실행합니다. iPhone 두 대에 동일한 iOS 앱을 설치합니다. 개발용 Mac에서는 각 폰의 잠금을 풀고 이 컴퓨터를 신뢰한 뒤 `npx expo run:ios --device --configuration Release --no-bundler`를 실행해 설치 대상을 선택할 수 있습니다. 설치나 실행이 막히면 iPhone의 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동 후 허용합니다. 필요한 경우 **설정 → 일반 → VPN 및 기기 관리**에서 앱 개발자를 신뢰합니다. 두 번째 폰이 서명 프로필에 없다는 오류가 나면 Xcode의 자동 서명에서 그 기기를 등록해야 합니다. 매장폰에 관리자 PIN이 아직 없다면 앱의 **매장용 → 초기 설정**에서 운영자가 가진 설정 코드로 PIN을 만듭니다. PIN은 두 폰 간 공유되지 않습니다.
2. Mac 터미널에서 `npm run demo:server`를 실행하고 열린 상태로 둡니다. 출력된 `http://<Mac의 Wi-Fi IP>:8787` 주소와 **고객 연결 코드**, **매장 연결 코드**를 확인합니다. 연결 코드는 10분 동안 유효하고 한 번만 사용할 수 있습니다. Mac 방화벽이 묻는 경우 Node 서버로 들어오는 로컬 네트워크 연결을 허용합니다.
3. 고객폰의 **설정 → 두 폰 연결**에서 `고객폰`을 선택하고 Mac 주소와 고객 코드를 입력합니다. 매장폰에서는 `매장폰`과 매장 코드를 입력합니다. iOS가 로컬 네트워크 권한을 요청하면 허용합니다. 두 설정 화면 모두 `연결됨`인지 확인합니다. 코드는 영상에 노출하지 마세요.

Mac에 주소가 여러 개 보이면 폰과 같은 Wi-Fi의 주소를 사용합니다. `0.0.0.0`이나 `localhost`는 폰에 입력하는 주소가 아닙니다.

## 촬영 순서

1. 매장폰에서 **매장용** 화면의 PIN 잠금을 풀고 성심당 지점을 선택합니다. `전체 대기 인원`을 입력해 저장합니다.
2. 고객폰에서 같은 지점을 선택하고 필수 동의에 체크한 뒤 **줄서기**를 누릅니다. 자동으로 `줄서기` 탭으로 이동해 발급 번호, 앞사람 수, 예상 대기시간을 보여 줍니다. 예상 시간은 앞사람 4명당 약 1분으로 계산한 추정치이며 실제 입장 시각이 아닙니다. 전체 대기 인원을 수동 변경해도 내 앞사람 수와 추정치는 자동 보정하지 않습니다.
3. 고객폰에서 주변 가게의 혜택을 확인하고 **쿠폰 발급**을 누릅니다. 매장폰의 **쿠폰 인증**에서 같은 가게를 선택하고 고객폰 QR을 스캔하거나 코드를 직접 입력합니다. QR 스캔 성공 시 매장폰 중앙의 초록 체크 `인증 완료` 팝업을 확인하고, 고객폰 쿠폰함의 `사용 완료`를 확인합니다. 같은 코드를 다시 입력해 중복 사용 거절도 보여 줄 수 있습니다.
4. 매장폰에서 해당 지점의 **앞사람 처리**를 반복합니다. 고객폰의 앞사람 수가 0명이 되면 **입장 QR 보기**를 누릅니다. 매장폰의 **입장 인증**에서 QR을 스캔하거나 코드를 입력합니다. QR 스캔 성공 시 초록 체크 팝업과 고객폰의 `입장 인증 완료`를 확인합니다. 같은 입장 코드는 다시 인증되지 않습니다.

두 폰은 앱이 전경에 있을 때 약 1초 간격으로 새 상태를 확인합니다. 연결이 끊기면 변경 버튼이 동작하지 않으며 로컬 기록으로 대신 저장하지 않습니다. Mac과 Wi-Fi를 복구하면 서버 상태가 다시 표시됩니다.

## 코드 재발급과 초기화

서버가 실행 중인 **같은 Mac 터미널**에 다음 중 필요한 명령을 한 줄씩 입력합니다.

```text
reissue customer
reissue merchant
reset --confirm-reset
```

`reissue customer` 또는 `reissue merchant`는 해당 역할의 기존 연결만 무효화하고 새 연결 코드를 출력합니다. 줄서기와 쿠폰 기록은 유지됩니다. 폰에서 **설정 → 연결 해제** 후 새 코드로 다시 연결하세요. `reset --confirm-reset`은 새 테이크를 위한 전체 초기화로, 줄서기·쿠폰·사용 이력과 두 폰의 연결을 모두 지웁니다. 복구할 계획이 없다면 실행하지 마세요. 단순히 폰에서 연결을 해제해도 Mac의 기록은 삭제되지 않습니다.

## 범위

한 촬영 세션은 고객폰 한 대와 매장폰 한 대만 지원합니다. 앱의 QR 확인은 Mac 서버 내부 기록을 변경하며 실제 매장 POS·웨이팅 시스템과는 연결되지 않습니다. 관리자 PIN과 연결 코드는 촬영용 접근 제한이지 서버 기반 운영자 인증이 아닙니다. 공개 Wi-Fi, 개인정보나 결제정보에는 사용하지 마세요. Mac을 종료하거나 다른 네트워크로 이동하면 두 폰은 실시간으로 연동되지 않습니다.

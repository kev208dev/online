# ONLINE

성심당 본점의 기다림을 주변 은행동 로컬 상점 방문 기회로 바꾸는 모바일 시연 앱입니다. Expo 58, React Native, TypeScript, Expo Router로 구현했습니다.

## 실행

Node.js 24와 Xcode가 필요합니다.

```bash
npm install
npx expo run:ios
```

iOS Liquid Glass 하단 바, 카메라 QR 스캔, 로컬 알림을 포함하므로 실제 기능 확인에는 네이티브 빌드가 필요합니다. 연결된 iPhone을 지정할 때는 `npx expo run:ios --device <UDID> --configuration Release --no-bundler`를 사용합니다.

## 시연 흐름

1. 홈에서 앵커 매장 성심당 본점의 **예상 대기시간을 직접 입력**합니다. 줄을 떠나도 되는지 확인한 경우에만 주변 방문 일정을 만들 수 있습니다.
2. 홈 추천 또는 검색에서 은행동 매장을 보고 상세 화면에서 일정에 담습니다. 이동·체류·복귀 여유(5분)를 합쳐 남은 시간보다 긴 일정은 추가하지 않습니다.
3. 상세에서 시연 쿠폰을 발급하고 쿠폰함에서 개별 QR과 발급·사용·만료 상태를 확인합니다. 한 대기 기록에서 매장당 한 번만 발급합니다.
4. 설정 → 매장용 시연 화면에서 쿠폰 코드를 선택/입력하거나 카메라로 QR을 스캔해 사용 처리합니다. 다른 매장, 만료, 중복 사용은 거절합니다.
5. 일정 탭에서 순서·현재 방문 중인 매장·방문 완료·삭제를 관리하고 앵커 매장 복귀 시각을 확인합니다. 앱 안에서는 알림 권한과 관계없이 복귀 안내가 표시됩니다. 설정에서 기기 알림을 켜면 같은 예상 시각 기준 로컬 알림도 예약합니다.

데모 데이터는 기기에 저장되어 재실행 후 유지됩니다. 설정에서 확인 후 초기화할 수 있습니다.

## 시연 한계

- 성심당의 실제 웨이팅 시스템이나 제휴 상점과 연결되지 않습니다. 표시된 혜택은 **시연 데이터**이며 실제 할인 제공을 뜻하지 않습니다.
- 쿠폰 검증 상태는 해당 기기 안에만 저장됩니다. 두 기기 간 인증·매장 권한·실제 결제·부정 사용 방지에는 서버가 필요합니다.
- 지도 이미지는 시연 자료입니다. 매장 상세에서 카카오맵 검색을 열어 실제 위치를 확인할 수 있습니다. 소요시간은 고정 추정치이며 실시간 경로나 GPS가 아닙니다.
- 영업시간 또는 주소가 확인되지 않은 매장은 준비 중으로 표시합니다. 실제 서비스 전에 상점 제휴와 매장 정보를 확인해야 합니다.
- 입장 QR, 실제 대기 순번/미루기/취소, 자동 호출 연동은 구현 범위가 아닙니다. 앱의 “기록 종료”는 실제 매장 대기를 변경하지 않습니다.

## 실서비스 전환 제안

기존 모바일 코드는 유지하고 TypeScript API + PostgreSQL을 추가하는 구성이 적합합니다. 서버에서 매장 계정과 역할을 확인하고, 쿠폰 발급 및 사용을 단일 트랜잭션으로 처리해야 기기 간 중복 사용을 막을 수 있습니다. 지도는 카카오맵 또는 네이버 지도의 라이선스·키·비용·매장 데이터 공급 방식을 확인한 뒤 결정합니다. 실제 웨이팅 연동은 앵커 매장과 별도의 협력이 필요합니다.
